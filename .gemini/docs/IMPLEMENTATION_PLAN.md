# План реализации: Дополнительный сплиттер, Улучшенный прогресс-бар, Дефолтная ширина дерева, Центрирование и Новая статистика

## Описание целей
1. Добавить вертикальный сплиттер `QSplitter` в правой части контента, чтобы можно было изменять высоту панели лога (`log_frame`) по отношению к верхним панелям настроек и выбора папок, а также полностью скрывать лог.
2. Настроить сохранение и восстановление высоты лога в сплиттере в файле `config.json`.
3. Улучшить внешний вид `QProgressBar`: сделать его более современным (градиентный сине-фиолетовый чанк, тонкие рамки, скругленные углы).
4. Установить дефолтную ширину левого дерева пациентов равной 220 пикселей.
5. Обеспечить центрирование окна программы при первом запуске (если нет сохраненной геометрии в `config.json`).
6. Добавить перевод для статуса выбора и внедрить подробный подсчет обнаруженных пациентов и исследований в `update_selection_label()`.

## План проверки

### Вручную
1. **Вертикальный сплиттер лога:** Перетащить разделитель над логом. Убедиться, что лог можно сжимать до нуля (скрывать).
2. **Прогресс-бар:** Убедиться, что индикатор прогресса имеет современный градиентный дизайн.
3. **Ширина дерева 220px:** При первом запуске (или удалении `config.json`) ширина левого дерева должна быть ровно 220 пикселей.
4. **Центрирование:** Удалить `config.json` и запустить программу. Окно должно открыться точно по центру экрана.
5. **Статистика в статус-лейбле:**
   - До сканирования отображается `Выбрано файлов: 0 / 0 (Пациентов: 0, Исследований: 0)`.
   - После сканирования отображается точное количество выбранных файлов из общего количества, а также число найденных пациентов и исследований.
