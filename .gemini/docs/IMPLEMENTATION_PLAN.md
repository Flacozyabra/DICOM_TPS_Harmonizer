# План реализации: Двухуровневое скрытие панелей и Фиксация размеров настроек

## Описание целей
1. Настроить сплиттер лога (`right_splitter`) так, чтобы при перетаскивании разделителя вниз блоки папок и настроек не растягивались по высоте (всё свободное место должен забирать лог).
2. Реализовать двухуровневое скрытие блоков в правой панели при движении сплиттера вверх: сначала скрывается блок галочек (`settings_frame`), а при движении еще выше — блок выбора папок (`folder_frame`).
