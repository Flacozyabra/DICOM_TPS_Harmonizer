# План реализации: Подсказки, QSplitter, темные диалоги и сохранение геометрии

## Описание целей
1. Добавить всплывающие подсказки (tooltips) для кнопок создания и открытия папок ввода/вывода на двух языках (русский и английский).
2. Исправить темную тему заголовков окон (Title Bar) для диалогов и главного окна, перенеся логику вызова DWM API в `showEvent` для надежного применения темы на Windows.
3. Внедрить горизонтальный сплиттер `QSplitter` для изменения ширины дерева объектов (пациентов) с возможностью сжатия дерева до 0 (скрытия) и стилизацией разделителя в темной теме.
4. Реализовать сохранение/восстановление геометрии главного окна и состояния сплиттера в `config.json` с использованием `saveGeometry`/`restoreGeometry` и `saveState`/`restoreState`.

## План проверки

### Вручную
1. **Подсказки:** Навести мышь на кнопки создания/открытия папок. Проверить, что текст подсказки соответствует текущему языку, а при переключении языка подсказки меняются.
2. **Темный заголовок диалогов:** Открыть окно прогресса сканирования (нажать "Сканировать"). Убедиться, что верхняя полоса заголовка имеет темный цвет.
3. **QSplitter:** Потянуть разделитель между деревом и контентом. Проверить, что дерево сжимается до нуля (скрывается). Проверить визуальную подсветку разделителя при наведении мыши.
4. **Сохранение геометрии:** Изменить размер и положение окна, сдвинуть сплиттер (или скрыть дерево). Закрыть и открыть приложение снова. Убедиться, что все размеры, координаты и состояние дерева восстановились.
